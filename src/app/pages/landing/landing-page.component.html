Welcome to SNOMED International's New Reference Set Management Tool!


SNOMED International's new Reference Set Management Tool builds upon the Reference Set and Translation Tool. It builds upon the existing tool by adding a modern interface, a better modeling user experience, richer capabilities, and integrates directly with Snowstorm.

Functionality Includes:

  • Full integration with SNOMED's Snowstorm Terminology Server
  • Flexible content review workflow
  • Enhanced in-tool communication
  • More powerful comparison capabilities
  • Improved upgrade wizard
  • Collaborate with others outside your organization
  • Guest access planned for future
