Welcome to SNOMED International's New Reference Set Management Tool!


SNOMED International's new Reference Set Management Tool builds upon the Refset and Translation Tool. It builds upon the existing tool by adding a modern interface, a better modeling user experience, richer capabilities, and integrates directly with Snowstorm.

Functionality Includes:

  • Full integration with SNOMED's Snowstorm Terminology Server
  • A flexible review workflow
  • More powerful comparison capabilities (In Development)
  • Collaborate with others outside your organization (In Development)
  • Ability to browse published reference sets as a guest
