Requirements when creating a new refset:
  1. Every Reference set has an associated SNOMED concept.
  2. Each SNOMED concept must have a parent SNOMED concept specified.


So...
  • If you are creating a new Reference set using an existing SNOMED concept, you must select the existing SNOMED concept to use.
  • If you are creating a new Reference set and wish to create a new SNOMED concept, you must select a SNOMED concept parent.
 A reference set whose members are defined by an enumerated list of concepts. A reference set whose contents will be initialized from the contents of two or more existing reference sets. This will create a new intensional reference set.
